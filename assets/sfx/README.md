# Sound effects

Drop audio files here (`.mp3 .wav .ogg .m4a .aac .flac`). One level of sub-folders
becomes the category in the Assets browser (`sfx/whoosh/air-whoosh.mp3` → Whoosh).
An optional `<name>.json` sidecar can set `{ "name": "Display name" }`.

The bundled files were synthesized for OpenChatCut and are free to use.
